# AURA — AI-Directed OLED Music Visualizer & Synced Lyrics

A lightweight, 60fps pure-OLED dark-room music stage with instant song search, real-time synced lyrics, album-matched perimeter ambient edge lighting, and optional Gemini 4 AI vibe direction.

## Live Demo
👉 **https://pranjal3125.github.io/aura-music/**

## Features
- **Instant Song Search**: Search Hindi, Bollywood, Indie & Global tracks (320kbps full streams + Apple catalog + local MP3 drag-and-drop).
- **Real-Time Synced Lyrics**: Powered by LRCLIB across 4 minimal styles (`Constellation`, `Apple Lyrics`, `Editorial Serif`, `Codestyle`).
- **Zero-Lag GPU Edge Lighting**: Pure CSS-composited ambient perimeter glow reactive to live audio bass & beats.
- **Autonomous AI + Optional Gemini 4 Director**: Automatically adapts colors, mood, lyrics style, and atmosphere to each song.
- **Dual-Monitor Companion Mode**: Open `?mode=companion` (`C`) on a second screen for a synced spinning vinyl + edge glow setup.
